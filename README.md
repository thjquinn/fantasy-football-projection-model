# Fantasy Football Projection Model

An end-to-end machine-learning project that predicts each experienced NFL player's total full-PPR fantasy points for the upcoming season.

The final projections will be combined with average draft position, value over replacement, and positional scarcity to support fantasy football draft decisions.

## Initial Scope

- QB, RB, WR, and TE
- Full-PPR scoring
- Season-level projections
- Players with at least one prior NFL season
- Approximately 8–10 seasons of historical data
- Rookies excluded from version 1

## Prediction Target

Total full-PPR fantasy points scored by a player in season `t`.

All model features must be based only on information available before season `t` begins.
